Dores Identificadas e Soluções Factorial

1

🚨 Sistema de Ponto - URGENTE

Dor:

Aproximação com sindicato para acordos de PLR em 2025. Não existe sistema de ponto hoje. Usam apontamento de horas em projetos como base para banco de horas, mas não atende requisitos legais. Necessidade urgente de implementar antes das negociações.

Solução Factorial:

  • ✓ Controle de ponto web (100% remoto) e mobile
  • ✓ Banco de horas automático e diário
  • ✓ Espelho de ponto completo para contabilidade
  • ✓ Aprovações pelo celular (gestor e RH)
  • ✓ Integração automática com férias e ausências
  • ✓ Atende requisitos legais para negociação sindical
2

Processos Manuais e Descentralizados

Dor:

Informações espalhadas: planilhas Excel, SharePoint, Teams, Drive. Cada processo fica em lugar diferente. Sem base de dados consolidada. Risco constante de informações desencontradas. Muitas tarefas operacionais que impedem trabalho estratégico.

Solução Factorial:

  • ✓ Sistema único integrado: tudo em um só lugar
  • ✓ Base de dados consolidada e estruturada
  • ✓ Portal centralizado para colaborador e gestor
  • ✓ Eliminação de planilhas e processos manuais
  • ✓ Informações sempre atualizadas e sincronizadas
  • ✓ Mais tempo para projetos estratégicos (cargos/salários, clima, universidade corporativa)
3

Gestão de Projetos e Custos de Colaboradores

Dor:

Controle de custos feito em planilhas. Custo ponderado do colaborador (salário + benefícios + provisões) calculado manualmente. Apontamento de horas em projetos (horas billable) separado do controle de custos. Necessidade de cruzar dados manualmente para calcular margem por contrato/cliente. Integração com Dynamics CRM é manual.

Solução Factorial:

  • ✓ Gestão de projetos integrada com apontamento de horas
  • ✓ Cálculo automático de custo hora ponderado
  • ✓ Alocação de horas por projeto/contrato
  • ✓ Cálculo automático de margem por cliente
  • ✓ API para integração com Dynamics CRM
  • ✓ Relatórios de rentabilidade e portfólio de clientes
  • ✓ Controle de horas billable vs. horas internas
4

Gestão Mista: CLT e PJ (60-70% PJ)

Dor:

Maioria dos colaboradores é PJ. Necessidade de gestão diferenciada: férias (15 dias a cada 12 meses para PJ), documentos (notas fiscais), benefícios (Convênia aplicado para todos). Sistema precisa atender ambos os perfis sem criar risco trabalhista. Planos de carreira para PJ é desafio.

Solução Factorial:

  • ✓ Gestão unificada de CLT e PJ na mesma plataforma
  • ✓ Contador de ausências para PJ (não chama "férias")
  • ✓ Pasta específica para notas fiscais de PJ
  • ✓ Gestão de benefícios para ambos os perfis
  • ✓ Avaliação de desempenho para PJ (já assumem risco de subordinação)
  • ✓ Banco de horas para CLT e PJ
  • ✓ Documentos ilimitados com assinatura eletrônica
5

Admissão e Gestão de Documentos

Dor:

Processo de admissão via e-mail e planilhas. Documentos espalhados. PJs enviam notas fiscais por e-mail para financeiro. Contratos PJ feitos manualmente. Uso de D4Sign (limite de 20 assinaturas/mês, custo adicional). Solerites precisam ser separados manualmente e enviados um por um.

Solução Factorial:

  • ✓ Fluxo de trabalho completo de onboarding
  • ✓ Admissão digital com coleta de documentos
  • ✓ Assinatura eletrônica ilimitada (sem custo extra)
  • ✓ Distribuição automática de solerites por colaborador
  • ✓ Organização automática em pastas (contratos, dependentes, etc.)
  • ✓ Modelos de documentos personalizados (contrato PJ, etc.)
  • ✓ Integração com Dynamics para cadastro automático
6

Gestão de Férias e Ausências

Dor:

Controle manual via planilhas e cards no Planner. Gestor negocia com PJ via WhatsApp, depois Ellen inicia processo. Sem visibilidade clara de quem está de férias. Processo fragmentado e trabalhoso.

Solução Factorial:

  • ✓ Solicitação pelo app mobile
  • ✓ Aprovação pelo gestor (visão de calendário da equipe)
  • ✓ Contador automático: 15 dias PJ (a cada 12 meses) | 30 dias CLT
  • ✓ Calendário consolidado da equipe
  • ✓ Histórico completo de ausências
  • ✓ Atestados digitais integrados
7

Pesquisas de Clima e Avaliação de Desempenho

Dor:

Avaliação semestral básica via planilha. Pesquisa de clima há anos sem ser feita. Uso de Microsoft Forms. Falta de aderência. Processo trabalhoso e difícil de executar.

Solução Factorial:

  • ✓ Pesquisas respondidas pelo celular (aumenta aderência)
  • ✓ Pesquisa de clima 100% anônima (LGPD/GDPR)
  • ✓ Avaliação semestral com competências (escala 1-4)
  • ✓ Autoavaliação + validação do gestor
  • ✓ Mapa de teia de competências
  • ✓ Agendamento automático e lembretes
8

Integração Microsoft e Analytics

Dor:

Necessidade de integrar com Dynamics CRM, Power BI, Azure. Dados precisam ser exportados manualmente. Fabiana usa Power BI extensivamente (25 painéis) e precisa de dados estruturados, não apenas dashboards.

Solução Factorial:

  • ✓ Integração nativa com Microsoft (Outlook, Calendar, Dynamics, Azure)
  • ✓ API completa e bem documentada
  • ✓ Editor SQL integrado para queries personalizadas
  • ✓ Exportação em XLSX, CSV para Power BI
  • ✓ SSO com Microsoft (login único)
  • ✓ Integração com Dynamics para cadastro automático de colaboradores
